# roastcommons.github.io

Public static pages for RoastCommons. `download/` is the download page (its buttons point at the latest release of
RoastCommons/releases). `r/` is where a review card's QR code leads
(`https://roastcommons.github.io/r#<pack id>.<code id>.<code>`): the part after `#` never reaches a server, and
the page loads nothing from anywhere else. Source: `docs/roastcommons_pages/` in the RoastLab repository.
