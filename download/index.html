Mac：第一次打开 First open on a Mac

测试版没有经过苹果公证，第一次打开会提示“无法验证”。只需要做一次：

  1. 打开下载的 .dmg，把 RoastCommons 拖到「应用程序」。
  2. 双击打开一次，看到提示点「完成」（不要移到废纸篓）。
  3. 打开「系统设置 › 隐私与安全性」，往下找到 RoastCommons，点「仍要打开」，输入电脑密码。
  4. 第一次运行时系统可能请你安装苹果的「命令行工具」，点「安装」，几分钟后再打开 app。

The beta is not notarized: open it once, click Done, then System Settings › Privacy & Security › Open Anyway. If macOS offers Apple's command line tools, install them and open the app again.

Windows：第一次打开 First open on Windows

  1. 双击下载的 .exe，不需要安装，也不需要 Python。
  2. 如果出现「Windows 已保护你的电脑」，点「更多信息 › 仍要运行」。

No installer needed. If SmartScreen appears, click More info › Run anyway.

还需要什么 What else you need

  • Artisan：免费的烘焙记录软件，从 artisan-scope.org 下载。app 会帮你打开它的自动保存。
    Free roast logger; the app turns on its autosave for you.
  • GitHub 账号：第一次打开时用 GitHub 登录。测试版只对成员开放，不是成员的话在 app 里点「申请加入」，管理员批准后自动解锁。
    Sign in with GitHub. The beta is invite-only: press Request to join in the app and an owner approves it.
  • 助手（可选）：在 app 里一键安装 opencode，再填你自己的模型 API key。
    Optional assistant: one-click opencode install inside the app, plus your own model key.
